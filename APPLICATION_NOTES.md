# Application Notes

These notes summarize the project for maintainer applications, grant forms, and project listings.

## Project Summary

Deep Analysis is an open-source Codex skill that packages an original structured-analysis framework into reusable AI-agent instructions. It helps users separate evidence from narrative, identify high-leverage anomalies, trace causal mechanisms, map incentives, test counterarguments, and attach uncertainty or probability estimates to forecasts.

## Maintainer Role

The repository owner is the original author and primary maintainer of the method. Maintenance work includes refining method wording, reviewing examples, triaging method proposals, validating skill metadata, and publishing release-ready versions of the skill.

## Ecosystem Value

The project is useful for AI-agent users and open-source maintainers who need disciplined analysis of product decisions, policy proposals, incident postmortems, research questions, or strategic tradeoffs. It provides a reusable reasoning workflow rather than a one-off prompt.

## Current Maintenance Evidence

- Initial public repository with MIT license, contribution guide, security policy, examples, and validation workflow.
- Open issues tracking extended methods, worked examples, and release preparation.
- Pull-request workflow used for project notes and future updates.

## Near-Term Roadmap

1. Rename the repository to `deep-analysis` or `deep-analysis-skill` if available.
2. Add complete worked examples for product, policy, and research cases.
3. Evaluate the extended 12-method draft and promote stable methods gradually.
4. Publish a `v0.1.0` release after CI passes and examples are reviewed.
