# Consistency Audit

Use before final output or whenever the user points out a contradiction.

## Goal

Catch contradictions, factual mistakes, probability incoherence, and framework drift.

## Procedure

1. Extract the main claims from the analysis.
2. Check whether claims contradict each other.
3. Check whether facts and interpretations are mixed.
4. Check whether probability ranges are coherent.
5. Check whether the answer drifted away from the user's question.
6. Correct the analysis directly.

## Output

```text
Audit findings:
- No issue found / issue found

If issue found:
- Contradiction:
- Correction:
- Updated conclusion:

Residual uncertainty:
```
