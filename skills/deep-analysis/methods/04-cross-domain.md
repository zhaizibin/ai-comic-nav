# Cross-Domain Comparative Analysis

Use when a pattern from one domain may apply to another domain, or when an analogy can test a mechanism.

## Goal

Compare structures, not surface labels.

## Procedure

1. Extract the source-domain mechanism in abstract terms.
2. Map source-domain elements to target-domain elements.
3. Identify where the analogy holds.
4. Identify where it breaks.
5. Generate predictions that would be true if the transfer is valid.
6. Feed results back into the causal or incentive analysis.
