# Layered Information Decomposition

Use when sources conflict, a narrative is messy, or the user asks what is fact versus interpretation.

## Goal

Separate the input into layers so the analysis does not argue at the wrong level.

## Layers

| Layer | Meaning | Evidence Standard |
| --- | --- | --- |
| Fact | Verifiable claim about what happened | Documents, data, direct observation, credible reporting |
| Narrative | How a source frames what happened | Source selection, omission, emphasis |
| Interpretation | Explanation of why it happened | Logical fit with facts and mechanisms |
| Meta-interpretation | Why a source promotes a frame | Incentives, audience, institutional position |

## Procedure

1. Extract all major claims.
2. Place each claim in one layer.
3. Mark claim status: verified, plausible, disputed, unsupported, or unknown.
4. Identify which narratives are being treated as facts.
5. Pass the clean map to the next method.

## Output

```text
Facts:
- ...

Disputed or unsupported claims:
- ...

Narratives:
- Source A frames it as ...
- Source B frames it as ...

Interpretations:
- ...

Meta-level incentives:
- ...
```
