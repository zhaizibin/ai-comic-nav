# Multi-Party Game-Theory Modeling

Use when three or more actors make interdependent decisions.

## Goal

Model actors, constraints, strategies, and likely equilibria.

## Procedure

1. Identify primary actors, influencers, and hidden stakeholders.
2. For each actor, list goals, resources, constraints, red lines, and current strategy.
3. Build a pairwise relationship map: cooperate, compete, deter, depend, or exploit.
4. Identify decision nodes and information asymmetries.
5. Estimate stable and unstable equilibria.
6. Name what could change the equilibrium.
