# Devil's Advocate Deconstruction

Use after a draft conclusion exists. This is a stress test, not a decorative "other side" section.

## Goal

Attack the strongest assumption behind the analysis and either repair the structure or replace it.

## Procedure

1. Extract the two or three assumptions the conclusion depends on most.
2. Build the strongest counterargument against each assumption.
3. Look for structural counterexamples, not isolated exceptions.
4. Decide whether the original structure survives, needs repair, or should be replaced.
5. Explain how the conclusion changes.

## Output

```text
Core assumptions:
- ...

Strongest counterargument:
- ...

Damage assessment:
- Survives / needs repair / should be replaced

Repaired or replacement conclusion:
```
